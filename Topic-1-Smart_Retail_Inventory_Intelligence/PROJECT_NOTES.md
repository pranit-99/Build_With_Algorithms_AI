# Smart Retail Inventory Intelligence

## Business Problem

Retail businesses need to understand which products are selling
and which products are remaining in inventory.

This system will allow a user to:

1. Store retail product information.
2. Search products using product ID or name.
3. Analyze historical sales information.
4. Calculate basic statistics from sales data.
5. Generate a simple demand score.
6. Classify inventory as low, normal, or high demand.
7. Display the information through a web application.
